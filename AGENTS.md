# Project direction

New CAD functionality should be native to AirCAD. FreeCAD is no longer part of the intended project workflow; do not add FreeCAD integration or make new features depend on it. Existing legacy integration files should not be removed without an explicit request.

## Voice prototype

- Voice is a separate input layer in `web/src/voice/`; it resizes selected native rectangles and box extrusions along world X/Y/Z through `Commands.setDimension` and `Commands.extrude`. Do not route it through gesture recognition or FreeCAD.
- `voice_api.py` follows the organizer's `yibuapi_examples_20260918_v01` HTTP contract: `https://yibuapi.com/v1/chat/completions`, model `qwen3.5-omni-flash`, Bearer `YIBU_API_KEY`, and WAV data-URL `input_audio`. Credentials come only from the Python server environment; `.env` files are not loaded automatically and keys must never use `VITE_*` variables.
- The browser records up to 10 seconds, sends mono 16 kHz PCM16 WAV to `/api/voice/command`, and re-validates the command before dispatch. The schema supports signed delta changes and positive exact sizes along world axes (Z up). A flat rectangle can become a solid along its normal axis; dimensions may not collapse or invert. Restart Python from the same Terminal after backend changes so it retains its environment, then rebuild/reload the frontend as needed.
- `yibu_audit.py` is the unchanged organizer helper. Each upstream attempt records purpose `aircad_voice_resize_axis` and actual usage in `artifacts/yibu_api_calls.jsonl` (override with `YIBU_AUDIT_LOG`). Missing usage remains null. Do not log keys, prompts, or audio to this ledger, and do not silently bypass audit failures.
- Height/taller means world Z, width/wider means world X, and depth/thickness means the selected profile's extrusion axis. Unsupported rotated-axis edits are rejected rather than approximated; resizing keeps the native origin, orientation and extrusion sign.
- Voice world dimensions are bounding-box spans. Rotated rectangles/boxes use an exact native-dimension solve to change one world span while preserving the other spans, origin, orientation and extrusion sign; singular or collapsing solutions are rejected, never snapped or sheared. Simple full-match numeric X/Y/Z transcripts can recover a model-declined command locally, with the same size/orientation validation and no extra API call.
- The voice HTTPS request explicitly uses the certifi CA bundle with certificate and hostname verification enabled. Some macOS Python installations have no default CA bundle; do not work around that by disabling TLS verification.
- Focused checks: `.venv/bin/python -m unittest discover -s tests -p 'test_voice*.py' -v`; from `web`, `npm test -- src/voice/commands.test.ts src/voice/microphone.test.ts src/voice/control.test.ts src/main.test.ts src/model/commands.test.ts` and `npm run build`.
