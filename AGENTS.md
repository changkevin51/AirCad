# Project direction

New CAD functionality should be native to AirCAD. FreeCAD is no longer part of the intended project workflow; do not add FreeCAD integration or make new features depend on it. Existing legacy integration files should not be removed without an explicit request.

## Voice prototype

- Voice in `web/src/voice/` is a separate measurement input for active native line and face-pull sessions. It supplies a positive distance only; sessions own target/direction. No idle selected-object fallback or FreeCAD routing.
- Live voice uses the browser Speech Recognition API (`SpeechRecognition` / `webkitSpeechRecognition`) in Chrome or Edge on localhost or HTTPS. The browser streams a transcript; AirCAD parses a positive distance locally and never sends audio to Python or Yibu. Firefox and other browsers without that API fail immediately with a panel error. Credentials and `VITE_*` variables are not used for voice.
- Lines use a continuously refined free-angle voice guide from the last 12 movement-filtered drag samples after 32 screen pixels, within the active XY/XZ/YZ work plane at its actual 3D offset. Automatic grid/near-axis snaps do not quantize this guide; explicit X/Y/Z locks and on-plane object constraints are honored. V freezes the displayed direction; normal non-voice shape recognition stays unchanged. Face pulls use the current grab's baseline and the selected face's normal/sign, preserving the opposite face/orientation/extrusion sign for solids.
- V during a draw/pull captures and freezes the draft before listening. A transcript that full-matches a distance **with units** commits immediately (interim or final). Bare numbers wait for a final result or a second V. The user may release while listening. Valid results replace the rough distance and immediately commit one undoable edit. Esc cancels the draft/request; a failed/cancelled request can be retried on the frozen draft. Normal non-voice release-to-commit is unchanged.
- Leave `voice_api.py`, `yibu_audit.py`, `/api/voice/command`, and `web/src/voice/microphone.ts` in the tree unused. Do not wire them back into the live voice path.
- The command applied to CAD is `{distance_mm: number}`; context is `{operation: 'line'|'face_pull', units: 'mm'}`. Validate positive finite limits, exact geometry (no grid rounding/clamping), and stale operation identity/revision. Transcripts may contain number words; fold those to digits, then full-match a bare distance or 'by' distance. Legacy axis instructions are rejected.
- Focused checks: from `web`, `npm test -- src/voice/transcript.test.ts src/voice/speech.test.ts src/voice/control.test.ts src/voice/commands.test.ts src/main.test.ts src/model/commands.test.ts src/model/stroke.test.ts src/model/extrusion.test.ts src/model/faces.test.ts src/input/input.test.ts` and `npm run build`.
